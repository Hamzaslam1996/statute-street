# Rulings 11: refine owner type exceptions (Hamza, 4 Oct)

No API calls. Rulings_09 was too broad: it turned every rule with any owner carve out into unknown. Organisers' README 4 targets owner type TESTS that decide coverage (their example: the CA small landlord deposit exception). Refine as follows.

1. **Cooperatives and government ownership are not owner type tests.** A resident owned cooperative and a government owned unit are not landlord and tenant rental tenancies at all; they are a tenure or funding class. Move them to use_or_funding: data silent gives `applies`, explanation "Applies unless the property is a resident owned cooperative / government owned housing", listed in assumptions.
2. **Unit level carve outs inside the owner's own dwelling** (owner shares kitchen or bath, a roommate in the owner's unit, a room rented in an owner occupied home): they can remove at most the owner's own unit. When the use code shows 2+ units, apartments or multifamily, the address is covered: `applies` with the carve out listed in assumptions. Only single family, or unknown building type, stays `unknown`.
3. **Keep `unknown` (true owner type tests):** small landlord exceptions (natural person owning few properties or units), AB 1482 natural person single family / condo exception, owner occupied duplex or 2 to 4 unit exemptions where the unit count is within the threshold or unknown. Explanation names the missing fact ("owner identity is not in the data").
4. **Precedence follows automatically:** where the LA JCO or a Berkeley rule now applies, the state rule (Civ. Code 1946.2 / 1947.12) is `superseded` again. Update the test that encoded the rulings_09 behaviour.
5. **D076 (San Diego):** the corpus copy is the proposal PDF while the citation is enacted O-21955. Keep it as primary (organisers supplied it), add the note "corpus copy is the proposed text; enacted as O-21955" to the rule's notes, and confirm the quoted span is the operative prohibition.
